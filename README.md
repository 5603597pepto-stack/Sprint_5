# Sprint_5 — автотесты Stellar Burgers

Автотесты для веб-приложения [Stellar Burgers](https://stellarburgers.education-services.ru/) —
учебного сервиса «космического фастфуда», в котором пользователь может собрать
и заказать бургер из необычных ингредиентов.

Тесты написаны на **Python** с использованием **Selenium WebDriver** и **pytest**.

## Что покрыто тестами

1. **Регистрация** (`tests/test_registration.py`)
   - успешная регистрация нового пользователя;
   - ошибка при регистрации с некорректным (слишком коротким) паролем.

2. **Вход в аккаунт** (`tests/test_login.py`)
   - вход по кнопке «Войти в аккаунт» на главной странице;
   - вход через кнопку «Личный кабинет» в шапке сайта;
   - вход через кнопку «Войти» в форме регистрации;
   - вход через кнопку «Войти» в форме восстановления пароля.

3. **Навигация** (`tests/test_navigation.py`)
   - переход в личный кабинет;
   - переход из личного кабинета в конструктор — по кнопке «Конструктор» и по логотипу;
   - выход из аккаунта по кнопке «Выйти».

4. **Конструктор** (`tests/test_constructor.py`)
   - переходы между разделами «Булки», «Соусы», «Начинки».


## Установка и запуск

2. Запустите все тесты:

## Особенности реализации

- Каждый тест независим: открывает браузер, выполняет проверку и закрывает браузер
  (`driver.quit()` вызывается автоматически в фикстуре `driver` через `yield`).
- Для тестов, где нужен уже существующий пользователь (вход, навигация), используется
  фикстура `registered_user`.
- Логины (email) генерируются функцией `generate_email()` в уникальном формате
  `имя_фамилия_когорта_случайные3цифры@домен`, чтобы избежать конфликтов
  «пользователь уже существует» при повторных прогонах.
- Тесты запускаются в Google Chrome.
